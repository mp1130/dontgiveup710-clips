# Privacy Policy

Last updated: November 19, 2026

This policy covers the dontgiveup710 Clip Bot, a small personal tool that takes clips from the dontgiveup710 Twitch stream and uploads them as YouTube Shorts to the streamer's own YouTube channel. It is run by Michael Pompa for one channel and is not offered to the public.

## YouTube API Services

This tool uses YouTube API Services to upload videos. By using it, the channel owner agrees to the YouTube Terms of Service at https://www.youtube.com/t/terms

Google's Privacy Policy applies to data handled by Google: https://policies.google.com/privacy

## What it accesses

With permission given through Google sign in, the tool uses the YouTube Data API to upload videos (videos.insert) and to read the channel name (channels.list) so it can show which channel is connected. It does not read, store or share any other YouTube data, comments, analytics or data about viewers.

## What it stores

The Google sign in token is stored only on one private computer. It is never sent to anyone else and is not sold or shared. The tool does not collect personal data from viewers or any other Google user.

## Twitch data

The tool reads public Twitch chat messages and public stream info to decide which moments to clip. Chat messages are kept for a short time on the same private computer and are not shared.

## Deleting data and removing access

The channel owner can remove the tool's access at any time at https://myaccount.google.com/permissions

To have the stored token and clip data deleted, contact us below and it will be deleted within 7 days. Revoking access also stops the tool from working right away.
