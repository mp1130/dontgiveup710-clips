# Privacy Policy

Last updated: November 19, 2026

This page covers the dontgiveup710 clip uploader, a small personal tool that takes clips from the dontgiveup710 Twitch stream and uploads them as Shorts to the dontgiveup710 YouTube channel.

## What it accesses

The tool signs in to one YouTube channel, owned by the streamer, using Google sign in. It only uses that access to upload videos to that channel and to read the channel name so it can show which channel is connected.

## What it stores

The sign in token is stored on one private computer run by the streamer's family. It is never sent to anyone else. The tool does not collect, sell or share personal data from any viewer or any other Google user.

## Twitch data

The tool reads public Twitch chat messages and public stream info to decide which moments to clip. Chat messages are kept for a short time on the same private computer and are not shared.

## Removing access

The channel owner can remove access at any time at https://myaccount.google.com/permissions

## Contact

Questions: message dontgiveup710 on Twitch at https://www.twitch.tv/dontgiveup710

This tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
